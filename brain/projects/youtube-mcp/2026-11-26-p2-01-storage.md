## Goal

Implement Paul's P2-01 SQLite migrations, account-bound repositories, operation
intent storage, cache, expiry, deletion, and replay protection on the assigned
task branch.

## Outcome

Implemented versioned SQLite initialization and repository adapters for library
snapshots, proposals, cache entries, and operation intents. Account deletion
cascades account-owned records and preserves minimal replay tombstones. Runtime
defaults point to the per-user data directory, partitioned by fixture/live mode.
Added synthetic tests for restart, expiry, foreign-account reads and replay.
Added revision-safe operation updates and proposal state transitions without
changing A2-01 contracts. The Issue and draft PR exist; exact URLs are not
available in this checkout/session record.

- Existing A2-01 protocols supplied repository boundaries without changes.
- Synthetic contract fixtures provide account and snapshot cases without real
