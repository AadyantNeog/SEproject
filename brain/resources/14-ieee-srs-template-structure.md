# Teaching assistants SRS template structure

## Finding

The user supplied a legacy Word template from the teaching assistants and explicitly requested a separate SRS alongside the previous version. The template contains a right-aligned title cover, contents, revision history, Introduction, Overall Description, External Interface Requirements, System Features, Other Nonfunctional Requirements, Other Requirements, and appendices for Glossary, Analysis Models and To Be Determined items. Each feature has description/priority, stimulus/response and functional-requirement subsections.

## Project implication

Use the supplied structural and visual conventions in a new rendition while preserving all 46 baseline requirement statements. Remove instructional placeholders and the sample approval claim. Preserve the permission footer. Add the actual Random Stuff roster without inventing an institution. The request changes presentation and organisation; it does not authorise changing topics, declaring approval or deleting the prior SRS.

## Verification

The final rendition has 27 pages, 43 verified contents entries and a requirement-placement map. The original template and previous SRS PDF retain their hashes. See the new session record and `docs/requirements/SRS_IEEE_QA.md` outside the vault.
